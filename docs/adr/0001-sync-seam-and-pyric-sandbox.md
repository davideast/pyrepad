# Decouple synchronization behind a Reactive-Minimal Hybrid Seam and adopt Pyric for local sandbox testing

To modernize Firepad for 2026 agentive UI and eliminate fragile network mocks, we are decoupling `EditorClient` from Firebase Realtime Database v7 by introducing a **Reactive-Minimal Hybrid Seam** (`SyncSeam`). This deep interface exposes three independent streams (`operations`, `presence`, and `agentive`) to prevent high-frequency AI ghost diffs from blocking authoritative text edits, while fire-and-forget commit methods absorb all OT revision tracking, retry buffering, and rollback reconciliation inside the transport adapter. Furthermore, we adopt Pyric (`pyric/database` and `@pyric/cli`) as our exclusive local development sandbox and offline verification engine, replacing cloud-only project dependencies and heavy emulator suites with an in-memory TypeScript runtime.
